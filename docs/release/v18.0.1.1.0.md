# Release record v18.0.1.1.0

## What changed

- The attachment overview is on by default for document users. `Document User` now implies the
  `Attachment Overview` group, so every document user (and every document administrator) gets the
  menu without being given anything. The `Attachment Overview` group still exists and can be given
  alone to an internal user who is not a document user.
- The menu and the action are renamed. English: "Attachments in other apps"; Traditional Chinese:
  「各模組附件」. The menu sits right after the module's own Documents menu (sequence 30), before Trash.
- Every row says where it comes from. `ir.attachment` has two new fields that are computed when read and
  never stored: `woow_source_model_label` (the name of the kind of record; searchable by its name or
  its technical name) and `woow_source_record_label` (the name of the record, empty when it is gone or the
  user may not read it). A row button opens the source record; the form has a Download button.
- The overview has list, kanban and form views and a search view with the filters "Business records"
  (on by default), "My uploads", "Images", "PDF" and "Last 30 days", and the groupings Source type,
  Uploaded by and Upload month. All of them are read only.

## What did not change

- The overview shows exactly what the user's own search over `ir.attachment` returns. There is no new
  access right, no record rule and no privilege escalation for attachments.
- The module's own files stay out of the overview.
- The "add to documents" entry point still needs both groups, and works as before.

## Who gains the menu

Every user who is in `Document User` or `Document Administrator` and was not already in
`Attachment Overview`.

## Upgrade

`-u woow_document_management`. There is no schema change and there is no data migration: Odoo adds the
members of an implying group to the implied group when the implication is written.
